## v1.7.0 - 2026-10-19

Implements requirements 01-03 (and the download part of 04) from `docs/product/client-feedback-2026-10-15.md`.

- **Visitor-only site.** Visitors never sign in. Registration, email verification, Lightbox, Collections, Dashboard and creator profile pages are retired (old addresses redirect); save and download controls are removed; Contact is always anonymous.
- **Staff-only admin.** Only admin/super_admin accounts can sign in. New `/admin` hub (upload, works, inquiries, account). Upload asks only for title, series (此间留彩 / 此间留灰), introduction and tags; Publish goes live directly through the audited super-admin self-publish. The review queue, user administration, notifications and the browser-side editor are removed.
- **Upload prefill.** Title, caption and keywords are read from Lightroom/Photoshop metadata (XMP/IPTC) or the filename, and black-and-white photographs start in 此间留灰, colour ones in 此间留彩. Cmd/Ctrl+S saves, Cmd/Ctrl+Enter publishes.
- **English / 中文 switch** in the header; follows the browser language and remembers the visitor's choice. Chinese copy is a draft pending the photographer's review; photographer-entered content is not translated.
- No database schema changes.

## v1.6.10 - 2026-10-14

- The Contact form now checks the 10-character message minimum before submitting. Previously a short message passed the browser checks, the server rejected it, and the visitor only saw a generic "review the inquiry fields" error with no field highlighted.
- Contact inquiries are now emailed to the photographer through Brevo (`inquiries@mtdo.cn`, domain-authenticated), and Supabase Auth verification and recovery codes are sent through Brevo as `no-reply@mtdo.cn`. Both are provider configuration, not code changes.

## v1.6.9 - 2026-10-14

- Public creator profiles (used by About and `/creators/{slug}`) now share the public Works cache and background refresh, so they load instantly instead of taking 6-9 seconds. The same admin/profile write invalidation applies.
- Added an `MT` site icon (`favicon.svg`) to every page in place of the empty placeholder.

## v1.6.8 - 2026-10-14

- The anonymous public Works list is now cached for up to 120 seconds (`MT_PUBLIC_WORKS_CACHE_SECONDS`, 0 disables, capped at 240) and kept warm by a background refresher, so the archive answers instantly instead of waiting about 4 seconds on Supabase. Any write under `/api/admin/` or `/api/me/` clears the cache immediately, a list built before such a change is never stored, and cached responses report the remaining signed-URL lifetime truthfully.

## v1.6.7 - 2026-10-14

- Fixed the public Works archive, Home selected works, work detail, and Lightbox hanging on "Loading archive." The server signed every image derivative with its own Storage request, so 27 works took about 16 seconds and the browser's 12-second timeout aborted the page. Derivatives are now signed with one Storage batch request per bucket (3 provider calls instead of about 55); any asset the batch cannot sign still falls back to the original single-object request.

## v1.6.6 - 2026-10-13

- Contact inquiries can now email the photographer directly. New, non-replayed inquiries are sent in the background through a dedicated SMTP mailbox with the visitor as Reply-To; the inquiry is stored whether or not mail succeeds, logs contain only the opaque reference, and production preflight rejects a partial mail configuration. Disabled unless every `MT_INQUIRY_NOTIFY_*` value is set.
- Added `robots.txt` (private, account, and API routes excluded) and `sitemap.xml`, plus canonical, Open Graph, and Twitter card metadata on Home, Works, About, and Contact so shared links render a preview image.
- Nginx now gzip-compresses CSS/JS/SVG (styles.css 497 KB to about 76 KB) and lets browsers cache public static files: versioned CSS/JS for 30 days, unversioned CSS/JS for 10 minutes, `/assets/` images for 1 day. Any application `Cache-Control` (such as `no-store` on auth and workspace scripts) still takes precedence. API JSON stays uncompressed.
- Corrected `VERSION`, which had not been updated since 1.4.9.
